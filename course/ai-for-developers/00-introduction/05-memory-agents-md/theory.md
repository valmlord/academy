# Память агента и AGENTS.md

## Проблема

В репозитории CLAUDE.md на 162 строки, а агент всё равно запускает pytest напрямую и правит
сгенерированный код. Что из этого файла агенту на самом деле нужно?

Скорее всего, нужные строки там есть, но утонули среди описания архитектуры, дерева каталогов и
правил стиля, которые и так проверяет линтер. А часть строк устарела.

## Идея: память это контекст, а не конфигурация

Файл инструкций (CLAUDE.md, AGENTS.md) харнесс кладёт в контекст в начале сессии. Документация Claude
Code говорит прямо: эти файлы "context, not enforced configuration". Модель может им следовать, но
ничто не заставляет её это делать. Что на самом деле блокирует действие, разберём в следующем уроке.

Отсюда правило отбора: в файл попадает только то, что агент **не может вывести из кода**.

- Команды с подвохом: "тесты только через `make test`, он выставляет `APP_ENV` и тестовую базу".
- Ловушки: "каталог X перегенерируется, ручные правки пропадут".
- Запреты с причиной и правильной альтернативой: "никогда не делай Y, потому что Z; вместо этого W".

Чего в файле быть не должно:

- архитектуры и дерева файлов: агент читает репозиторий сам;
- правил, которые проверяет линтер или форматтер;
- пересказа README;
- IMPORTANT, ALL CAPS и восклицательных знаков. Рекомендации Claude Code: текущие модели следуют
  спокойно сформулированной строке, а нагромождение акцентов заставляет применять правило
  слишком широко. Если правило не терпит исключений, ему место в хуке или правиле запрета.

Размер: документация Claude Code советует держать CLAUDE.md меньше 200 строк. Это верхняя граница, а
не цель: файл из проблемы выше (162 строки) в неё укладывается и всё равно не работает. Короче лучше.

Что говорят исследования. Gloaguen et al. (arXiv:2602.11988v3, 2026-09-29; воркшоп MemAgents на ICLR
2026) нашли, что файлы контекста в среднем не повышали успешность задач и добавляли больше 20% к
стоимости инференса. Обзоры репозитория не помогали. Файлы, написанные разработчиками, были заметно
лучше сгенерированных моделью. Авторы предполагают, что лишние требования делают задачу труднее.
Lulla et al. показали выигрыш в эффективности от файла AGENTS.md. Вывод для практики: коротко,
конкретно, написано человеком.

## AGENTS.md и разные инструменты

AGENTS.md это открытый формат "README для агентов", который развивается под Agentic AI Foundation
(Linux Foundation). Его читают многие инструменты: Codex, Cursor, Gemini CLI, Copilot agent,
OpenCode и другие. Общее правило формата: ближайший к редактируемому файлу AGENTS.md важнее.

Порядок загрузки у каждого инструмента свой. Не переносите правило одного инструмента на другой.

### Codex (на 2026-10-27)

- Глобально в `~/.codex`: сначала `AGENTS.override.md`, потом `AGENTS.md`; берётся первый непустой.
- В проекте: от корня git до текущего каталога, по одному файлу на каталог. Файлы склеиваются от
  корня к листу, поэтому более глубокий идёт позже и при конфликте побеждает.

### Claude Code 2.1.311

**Области (scopes)**: managed (CLAUDE.md организации), пользовательская (`~/.claude/CLAUDE.md`),
проектная (`./CLAUDE.md` или `./.claude/CLAUDE.md`) и локальная (`CLAUDE.local.md`, не коммитится).

**Когда грузится**: CLAUDE.md в текущем каталоге и выше загружаются при запуске, в подкаталогах по
требованию, когда агент открывает там файл.

**Импорты**: строка `@path` в CLAUDE.md подключает другой файл. Импортированные файлы могут
импортировать дальше; документация (на 2026-10-28) называет максимум в четыре "hops", но не
уточняет, считается ли исходный файл, поэтому держите цепочки импортов короткими. Импорт
помогает организовать файлы, но **не экономит контекст**: импортированный файл грузится вместе с
тем, кто его импортирует.

**`.claude/rules/*.md`**: правила по темам. Правило с `paths:` во frontmatter грузится только когда
агент работает с подходящими файлами.

**Auto memory**: заметки, которые агент пишет сам. В начале сессии грузятся первые 200 строк или
25KB `MEMORY.md`.

**AGENTS.md при настройках по умолчанию**: Claude Code читает AGENTS.md, только если в текущем
каталоге и выше нет ни `CLAUDE.md`, ни `.claude/CLAUDE.md`, ни `CLAUDE.local.md`. Пользовательский и
managed CLAUDE.md не считаются. Если такой файл есть, грузится только CLAUDE.md, а AGENTS.md
попадает в контекст, только если CLAUDE.md импортирует его строкой `@AGENTS.md`. Когда AGENTS.md
читается, при запуске загружаются все `AGENTS.md` и `.claude/AGENTS.md` в текущем каталоге и выше.
Прямое чтение AGENTS.md требует v2.1.277 или новее.

Это поведение задаёт настройка **Project instructions** в `/config`. В файле настроек это
`pluginConfigs["cc-plugin-agents-md@builtin"].options.instructionFiles` (до v2.1.285 ID плагина был
`agents-md@builtin`). Значения:

| Значение | Что грузится |
|---|---|
| `claude-md-or-agents-md` (по умолчанию) | CLAUDE.md, или AGENTS.md, если нет CLAUDE.md и CLAUDE.local.md в текущем каталоге и выше |
| `claude-md-and-agents-md` | оба, в каждом каталоге сначала CLAUDE.md, потом AGENTS.md |
| `claude-md` | только файлы CLAUDE.md |
| `managed-only` | при запуске только managed CLAUDE.md и auto memory; CLAUDE.md подкаталогов, `.claude/rules/` и правила с `paths:` всё равно грузятся по требованию |

Настройка читается из `~/.claude/settings.json`, из файла `--settings` или из managed settings. В
проектных и локальных настройках она игнорируется.

## Пример: один файл для всех инструментов

Факты лежат в `AGENTS.md`, а Claude Code подключается к нему одной строкой:

```text
# CLAUDE.md
@AGENTS.md
```

Второй вариант: удалить CLAUDE.md совсем, тогда при настройках по умолчанию Claude Code прочитает
AGENTS.md сам.

## Частые ошибки

- Добавить AGENTS.md и оставить рядом старый большой CLAUDE.md: Claude Code по умолчанию AGENTS.md
  не прочитает.
- Обрезать старый файл вместо того, чтобы выбрать из него невыводимые факты.
- Писать запрет без причины и без альтернативы.
- Ждать, что строка "NEVER edit generated/" остановит правку. Это текст в контексте, не замок.
- Считать, что импорт экономит контекст.

## Что делать в практике

Вы найдёте в Makefile, README и комментариях кода факты, которые агент не выведет сам, напишете из
них короткий `AGENTS.md` и подключите его к Claude Code. Потом квиз: какие файлы загрузит конкретный
инструмент в конкретном дереве каталогов при настройках по умолчанию.

# Минимальный харнесс агента

Файлы:

| Файл | Что это |
|---|---|
| `harness.py` | Скелет `run_agent(...)`. Тело нужно написать вам. |
| `tool_server.py` | Внешний процесс с инструментами `read_file` и `word_count`: JSON-RPC 2.0 построчно через stdin/stdout. Протокол в стиле MCP, упрощённый и не соответствующий спецификации (нет `_meta`, `resultType`, `server/discover`, `ttlMs`/`cacheScope`, нет инициализации). |
| `fake_model.py` | Скриптовая "модель" для ручного прогона. Ничего не проверяет. |
| `demo.py` | Прогон: `python3 demo.py`. |

## Контракт `run_agent`

```python
run_agent(model, task, tool_server_cmd, local_tools, permission, max_turns) -> Result
```

- `model.complete(messages, tools)` возвращает один ход модели. Один вызов = один ход (turn).
  - вызов инструмента: `{"type": "tool_call", "id": "<id>", "name": "<имя>", "arguments": {...}}`
  - финальный ответ: `{"type": "final", "text": "<текст>"}`
- `messages` (список, который харнесс передаёт модели целиком на каждом ходе):
  - начинается с `[{"role": "user", "text": task}]`;
  - после каждого вызова инструмента харнесс добавляет ровно два элемента, по порядку: сам ход
    модели (словарь в том виде, как он пришёл) и
    `{"type": "tool_result", "id": "<id вызова>", "content": "<строка результата>", "is_error": false}`;
  - других элементов нет.
- `tools`: список `{"name": ..., "description": ...}`: все локальные инструменты (описание
  может быть пустой строкой) и все инструменты, которые внешний сервер вернул на `tools/list`.
- `tool_server_cmd`: argv внешнего сервера. Запустите его один раз за прогон, узнайте его
  инструменты через `tools/list`, вызывайте через `tools/call`, в конце завершите процесс.
  - запрос: `{"jsonrpc": "2.0", "id": 1, "method": "tools/call", "params": {"name": "...", "arguments": {...}}}`
  - ответ: `{"jsonrpc": "2.0", "id": 1, "result": {"content": [{"type": "text", "text": "..."}], "isError": false}}`;
    текст результата для модели: все `text` из `content`, склеенные через `\n`.
  - `isError: true` или поле `error` в ответе: результат для модели с `"is_error": true`.
- `local_tools`: `{имя: функция(arguments) -> str}`, выполняются в процессе харнесса.
- `permission(name, arguments) -> bool`: спрашивается до запуска любого инструмента (локального
  или внешнего). Если `False`, инструмент не запускается, а модель получает результат с
  `"is_error": true` и текстом об отказе.
- Неизвестное имя инструмента: результат с `"is_error": true`, харнесс не падает.
- `max_turns`: если после `max_turns` вызовов модели финального ответа нет, вернуть
  `Result(status="max_turns", text="", turns=max_turns)`.
- Финальный ответ: `Result(status="final", text=<text хода>, turns=<число вызовов модели>)`.

Только стандартная библиотека Python 3.10+.

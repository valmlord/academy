# Маршрутизация задач по моделям

`cards.json` содержит 6 карточек задач. В каждой карточке ровно одно ограничение жёсткое
(`situation`), остальные явно ослаблены (`relaxed`).

Заполните `routing.json`: для каждой карточки замените `null` значениями.

| Поле | Допустимые значения |
|---|---|
| `tier` | `frontier`, `large`, `mid`, `small` (уровни из таблицы в теории; для локального запуска это класс модели, которую реально запустить на этом железе) |
| `effort` | `low`, `medium`, `high`, `xhigh`, `max` |
| `deployment` | `cloud`, `local` |
| `binding_constraint` | `quality`, `latency`, `price`, `context`, `privacy`: ограничение, которое определило выбор |
| `reason` | одна строка, не длиннее 200 символов: почему так (читает ментор) |

Ключи карточек менять нельзя, лишние поля не добавляйте.

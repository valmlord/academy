# Ledger

В Billing account не говорим: в бухгалтерии это счёт учёта, и путаница уже дала неправильный отчёт.

## Language

**Account**: Счёт учёта из плана счетов компании, например выручка или расчёты с покупателями.

**Entry**: Запись в журнале: сумма по дебету или кредиту одного Account на дату.

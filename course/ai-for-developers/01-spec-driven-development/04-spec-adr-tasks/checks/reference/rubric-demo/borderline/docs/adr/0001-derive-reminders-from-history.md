# ADR-0001: Derive the next Reminder from the sent history on every run

Status: accepted

## Context

Отдел расчётов хочет три уровня Reminder со сроками 7, 14 и 14 дней. В старой системе даты всех
Reminder записывались в таблицу расписания при выставлении Invoice, и расписание расходилось с
жизнью при каждом изменении срока оплаты или частичном Payment. Команда по привычке ожидает такую
таблицу снова. Если на расписание завяжутся отчёты и другие сервисы, уйти от него можно будет только
миграцией данных.

## Decision

Мы не храним расписание. При каждом запуске `plan_reminders` выводит следующий Reminder из истории
отправленных Reminder, `due_on` и текущей даты. История отправленных - единственное состояние фичи.

## Consequences

- Reminder всегда согласован с текущим сроком оплаты.
- Не нужна таблица расписания.

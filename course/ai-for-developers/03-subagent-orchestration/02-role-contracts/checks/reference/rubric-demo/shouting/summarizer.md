# Контракт роли: summarizer

## Цель

Написать тимлиду итог ревью в трёх-пяти предложениях: можно ли принимать изменение и что мешает.
Принимать нельзя, если есть находка с `severity` `high` (сломано поведение или безопасность) или `medium`
(случай из критериев приёмки без теста); `low` приёмке не мешает. Работа закончена, когда итог опирается
только на переданные находки и перечисляет их `id`.

## Формат вывода

Объект по схеме `summarizer.schema.json`: `summary` это итог для человека, `finding_ids` это `id` находок, на
которых он основан.

# I02. Пакет, которого нет

Запись выдумана для упражнения: люди, репозитории и данные не настоящие.
Обозначения: `>` сообщение пользователя, `●` ответ или вызов инструмента агента, `⎿` результат инструмента.

**Контекст.** Этот репозиторий `invoice-service` до урока: `make check` запускает тесты и
архитектурный линтер, Stop-хук запускает тесты, правила `deny` для `pip install` нет. Проект
использует только стандартную библиотеку.

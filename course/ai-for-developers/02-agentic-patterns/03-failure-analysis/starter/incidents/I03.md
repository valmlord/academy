# I03. Метка времени по UTC

Запись выдумана для упражнения: люди, репозитории и данные не настоящие.
Обозначения: `>` сообщение пользователя, `●` ответ или вызов инструмента агента, `⎿` результат инструмента.

**Контекст.** Репозиторий `payments-sync`: `pyproject.toml` закрепляет `requires-python =
"==3.10.*"`, на серверах Python 3.10. `make check` запускает тесты интерпретатором `python3`,
который у разработчиков 3.12. Хуков нет, доступа в интернет у агента нет.

**Отрывок сессии.**

> Сохраняй время синхронизации в UTC.
● Edit(src/sync/state.py)
● Bash(make check)
  ⎿ Ran 41 tests in 0.31s
  ⎿ OK
● Готово, время теперь хранится в UTC, проверки зелёные.

**Дифф.**

```diff
-from datetime import datetime
+from datetime import UTC, datetime
-    synced_at = datetime.now()
+    synced_at = datetime.now(UTC)
```

После выкладки сервис не запустился: `ImportError: cannot import name 'UTC' from 'datetime'`.
`datetime.UTC` появился в Python 3.11.
